# Synthetic development question decks
The deterministic generator supplies20 test inputs without needing the owner's school material. Run node scripts/generate-fixtures.mjs to create the JSON files in .cache/fixtures. Add --stress for5000 questions. --verify checks the committed manifest/template and exact repeatability without writing files.
Inputs include: valid/demo-full-120.json (four arithmetic topics), valid/demo-quick-30.json, single-1, boundary19/99, optional explanations, repeated concepts, Unicode/plain-text markup, reviewStats, and original/updated revisions. Invalid cases cover malformed JSON, empty deck, duplicate IDs, wrong option count, answer overlapping wrong option, non-string explanation, missing answer, unsupported deck type and forbidden prototype key. fixtures/manifest.json contains expected accept/reject results.
These are development fixtures, not a hardcoded curriculum. Players later upload ANY compatible deck. The generator and manifest are committed rather than hand-maintaining thousands of repetitive records; the full120/quick30 files are available after one dependency-free command. Codex can use the generator's exported fixtureSet() without filesystem writes.
The preparation validator is not the production browser importer. Runtime/E2E and save tests remain NOT IMPLEMENTED. Passing fixture checks does not prove gameplay works.
